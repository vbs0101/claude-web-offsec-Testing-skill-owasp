# Authentication Security Testing

Check:

- Login security
- Logout behavior
- Session fixation
- Session rotation
- Session expiration
- Password policy
- Password reset
- MFA
- MFA bypass
- Brute-force protection
- Account enumeration
- Remember-me functionality
- Cookie security
- CSRF protection
- Role handling
- Session persistence
- Token validation

Use dedicated authorized test accounts.

Never expose passwords, session tokens, cookies, API keys, biometric secrets,
or reset tokens in reports.
